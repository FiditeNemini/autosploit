3. Detailed Findings

CRITICAL Finding #1: CVE-2021-41773 — Apache Path Traversal + RCE

Target: dev.acme.com:443

CVSS: 9.8 (AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H)

Description: Apache HTTP Server 2.4.49 contains a path traversal vulnerability that allows reading arbitrary files. When mod_cgi is enabled, this escalates to remote code execution.

Attack Chain

1. subfinder discovered dev.acme.com → 2. httpx identified Apache/2.4.49 → 3. nuclei confirmed CVE-2021-41773 → 4. Manual curl verified /etc/passwd readable → 5. CGI-bin RCE confirmed via reverse shell

Impact

An unauthenticated attacker can execute arbitrary commands on the web server, leading to full server compromise, lateral movement, and data exfiltration.

Remediation

Upgrade Apache HTTP Server to version 2.4.51 or later. As an immediate mitigation, disable mod_cgi and restrict access to the server.

HIGH Finding #3: Exposed .git Directory

Target: staging.acme.com:443/.git/

CVSS: 7.5

Description: The .git directory is publicly accessible, allowing anyone to download the complete source code repository including commit history, configuration files, and potentially embedded credentials.

Remediation

Block access to .git directories in the web server configuration. Audit the repository for embedded credentials and rotate any found.
